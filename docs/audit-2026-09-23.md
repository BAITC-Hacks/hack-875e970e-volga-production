## Воспроизведение изолированного запуска

Создать временный override вне репозитория:

```yaml
services:
  app:
    ports: !override
      - "127.0.0.1:3017:3000"
    environment:
      OPENAI_API_KEY: ""
```

Команды выполненного запуска (нужна версия Docker Compose с поддержкой `!override`; установленная версия приняла конфигурацию):

```sh
docker compose -p sobrano-audit-20260923 -f compose.yaml -f /tmp/sobrano-audit-override.yaml up --build -d --wait
APP_URL=http://127.0.0.1:3017 node --import tsx scripts/smoke.ts
APP_URL=http://127.0.0.1:3017 npm run test:e2e
docker compose -p sobrano-audit-20260923 -f compose.yaml -f /tmp/sobrano-audit-override.yaml restart app
APP_URL=http://127.0.0.1:3017 node --import tsx scripts/verify-runtime.ts
docker compose -p sobrano-audit-20260923 -f compose.yaml -f /tmp/sobrano-audit-override.yaml down
```

Smoke/runtime и два браузерных скриншота по умолчанию перезаписывают исторические файлы: перед повтором сохранить их, новые свидетельства скопировать в отдельную папку, затем восстановить исходные. В этом аудите использовалась именно такая обёртка. Для повторного чистого запуска выбрать новое имя Compose-проекта; существующий кеш не удалять. Обычный запуск README по порту 3000 не требует override.
