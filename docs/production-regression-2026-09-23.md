# Исторические проверки production — 23 сентября 2026

Проверки выполнялись на публичном адресе https://sobrano-production.up.railway.app. Они относятся к версии приложения на момент прогона; актуальный выпуск описан в [Railway](railway-deployment.md).

## Проверенные сценарии

- Город, категория, формат, дата, бюджет, язык и длительность.
- Плотная и редкая категории, отсутствие категории и несовпадение условий.
- Граничная цена, занятость площадок и смена календарной даты.
- Повторяемость ответа, нормализация пожеланий, одновременные одинаковые запросы.
- Валидация некорректного ввода, раскрытие источников, управление календарём и основной путь с клавиатуры.

API-набор включал 40 HTTP-запросов: 16 допустимых сценариев, 21 негативный запрос и три одновременных повтора. Автоматические утверждения этого API-набора прошли. [Сохранённые запросы и ответы](evidence/regression-2026-09-23/api.json).

## Инструменты воспроизведения

```sh
node --import tsx scripts/production-regression.ts
node scripts/production-browser-regression.mjs
node scripts/production-exploration.mjs
```

Эти диагностические скрипты используют фиксированный production URL и перезаписывают файлы в `docs/evidence/regression-2026-09-23/`. Они требуют установленных зависимостей, браузеров и сети. Новые запросы могут расходовать API. Для текущего стандартного браузерного набора используйте `APP_URL` и `npm run test:e2e`, как описано в README.

Локальные проверки текущей версии: [отчёт](audit-2026-09-23.md). Выбор и отображение цитат: [описание](concrete-explanations-fix.md).
