# План и решения

Кейс: «Умный подбор подрядчиков (#79-lite)», креативные индустрии. Бюджет команды — 4 часа с начала реализации. Стек согласован: Next.js / TypeScript. Добавлены необязательные пожелания. По решению команды README — единственный материал для предпрезентации. Презентации, слайды, сценарии защиты и видеозаписи не готовим.

## Обязательный объём

1. Полный сценарий выбора до трёх подрядчиков, строгие ограничения и три исхода.
2. AI-сопоставление пожеланий с описаниями; индивидуальные объяснения из подтверждённых цитат.
3. Повторяемость, обработка сбоя OpenAI, проверка реальными запросами.
4. Docker Compose, воспроизводимый README и техническая проверка основного сценария.

## Этапы

- 0:00–0:25 — каркас, данные, доступ к OpenAI и Docker.
- 0:25–1:15 — подбор, кеш, API, тесты.
- 1:15–2:00 — объяснения и сбои.
- 2:00–3:00 — интерфейс, интеграция, Docker.
- 3:00–3:35 — проверка, исправления, README.
- 3:35–4:00 — финальная проверка, доработка README и сдача.

## Принятые решения

- Исходный CSV не изменяется; синтетические профили не добавляются.
- Нет регистрации, бронирования и CRM. Одна категория за запрос, бюджет на одного подрядчика.
- Модель не решает, кого пропустить через строгие фильтры.
- Свободная генерация объяснений на проверке дала неподтверждённые обещания. Вместо неё AI выбирает точную цитату; код проверяет источник и формирует итоговый текст. Это осознанное ограничение для достоверности.
- Кеш резервного режима тоже постоянный. Один процесс приложения; масштабирование потребует общего хранилища и блокировок.
- AGENTS.md сохранён; официальная таблица ТЗ приоритетнее общей таблицы из него: 25 / 25 / 25 / 15 / 10.
- Удалённый деплой выполнен после обязательных работ. Адрес и инструкция обновления: [Railway](railway-deployment.md).
- Управление анкетами через закрытый интерфейс администратора рассматривается как перспектива развития, а не часть текущего прототипа. Исходный каталог остаётся основой воспроизводимого демо; для развития нужны постоянное хранилище, валидация, обновление AI-индекса/кеша и процесс подтверждения цен и календарей.

Запуск, основной сценарий, ограничения и предпрезентация: корневой README. Фактические ответы: `docs/evidence/smoke.json`.

Явное решение команды о README отменяет требования к отдельным материалам защиты и резервной записи из AGENTS.md. Сам AGENTS.md не изменяем.
