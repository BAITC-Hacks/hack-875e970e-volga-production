# Решения по форме и исходному датасету

Обновлено 23 сентября 2026 года. Сводка завершённого рефакторинга; актуальные инструкции запуска — в [README](../README.md), продуктовые решения — в [плане](hackathon-plan.md).

## Форма

Выбрана Mantine: готовые Select, DatePickerInput, NumberInput, Textarea и Button обеспечивают согласованный интерфейс в разных браузерах. Тема сохраняет зелёно-кремовую палитру приложения. `@mantine/hooks` — обязательная peer dependency используемых компонентов.

Дата отображается как `DD.MM.YYYY`, передаётся в API строкой `YYYY-MM-DD` без преобразования через `Date.toISOString()`. Диапазон — 23.09–31.12.2026. Локаль dayjs зарегистрирована в клиентском `app/finder.tsx`: одного серверного импорта недостаточно для русских названий месяцев.

Тесты `tests/browser/controls.spec.ts` проверяют отправляемый JSON, календарь, клавиатуру, границы дат и мобильную ширину. В проверке полей запрос перехватывается, чтобы проверить контракт без вызова AI; реальные запросы покрываются отдельным набором `finder.spec.ts`.

## Датасет

Исходный CSV перенесён без изменения содержимого в `data/hackathon_dataset_anonymized.csv`. Сервер читает его из `data/`, Dockerfile явно копирует в образ. Данные не размещаются в публичной статической папке. SHA-256 до и после переноса совпал. Неиспользуемое HTML-превью удалено; оно доступно в истории Git.

## Проверка и ограничения

При завершении рефакторинга прошли TypeScript, production-сборка, 16 модульных тестов тогдашней версии и проверки контролов в Chromium, Firefox и WebKit. Эти исторические результаты не описывают количество тестов текущей версии.

После переноса CSV конфигурация Compose проверена, но сборка Docker-образа в той сессии не выполнялась из-за недоступного Docker daemon. Перед сдачей нужно подтвердить запуск текущей версии через `docker compose up --build` с чистого состояния.
